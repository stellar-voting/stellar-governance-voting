# Frontend — Stellar Governance Voting

React + TypeScript + Vite frontend for the governance voting protocol.

## Views
- Dashboard — Stats and recent proposals
- Proposals — Full table with detail modal
- Create — Create new proposal
- Vote — Cast votes on active proposals
- Admin — Manage voters, close/cancel proposals, pause
- Wallet — Freighter wallet integration

## Development
```bash
npm install && npm run dev  # :5175 (proxies /api to :3000)
npm run build
```
